VOCABULARY ADVENTURE — PRACTICAL EXAM AGE 6

Files:
- index.html
- style.css
- script.js

How to use:
1. Keep all three files in the same folder.
2. Open index.html in a modern browser (Chrome recommended).
3. On a phone, you can open index.html from a local HTML editor or upload the folder to your hosting.

Features:
- Seven exam topics: Numbers 21–100, Feelings, Five Senses, Fruits, Vegetables, Yard, Street
- Learn mode with English word, Indonesian meaning, emoji, example sentence
- Text-to-speech pronunciation using the browser's SpeechSynthesis feature
- Quiz mode with randomized multiple-choice questions
- Match mode to match English words with Indonesian meanings
- Spell mode for spelling practice
- Progress and stars saved in localStorage on the same browser/device
- Responsive layout for mobile and desktop

Notes:
- Pronunciation audio depends on the browser/device. Chrome usually works best.
- The web speech feature may require internet or installed English voice data on some devices.
- Progress is stored locally in the browser, not in a server database.
- For use in an online course platform, upload the three files to a folder on your web hosting.
